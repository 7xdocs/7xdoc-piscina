| API                                                                    | 描述                                                                                                                                                                                                                                                                                         |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Class: `Piscina`**                                                   | 此类扩展了 Node.js 的 [`EventEmitter`](https://nodejs.org/api/events.html#events_class_eventemitter)。                                                                                                                                                                                     |
| **Constructor: `new Piscina([options])`**                              | 创建 `Piscina` 类的新实例。 [可用选项列表](./class.md)                                                                                                                                                                                          |
| **Method: `run(task[, options])`**                                     | 调度要在 Worker 线程上运行的任务。                                                                                                                                                                                                                                                      |
| **Method: `runTask(task[, transferList][, filename][, abortSignal])`** | **已弃用** -- 请改用 `run(task, options)`。                                                                                                                                                                                                                                                 |
| **Method: `destroy()`**                                                | 停止所有 Worker 并拒绝所有待处理任务的 `Promise`。                                                                                                                                                                                                                                     |
| **Method: `close([options])`**                                         | 优雅地停止所有 Worker。                                                                                                                                                                                                                                                                       |
| **Event: `'error'`**                                                   | 当 Worker 线程内发生未捕获的异常或从 Worker 线程发送意外消息时发出。                                                                                                                                                                                                                                                                                                               |
| **Event: `'drain'`**                                                   | 每当 `queueSize` 达到 `0` 时发出。                                                                                                                                                                                                                                                       |
| **Event: `'needsDrain'`**                                              | 一旦排队等待执行的任务数量超过池的总容量，就会触发。                                                                                                                                                                                                                                                                                                           |
| **Event: `'message'`**                                                 | 每当从 worker 线程收到消息时发出。                                                                                                                                                                                                                                                                                                      |
| **Property: `completed` (readonly)**                                   | 当前完成的任务数。                                                                                                                                                                                                                                                              |
| **Property: `duration` (readonly)**                                    | 自创建此 `Piscina` 实例以来的时长（以毫秒为单位）。                                                                                                                                                                                                                                                                                                                 |
| **Property: `options` (readonly)**                                     | 当前由此实例使用的选项的副本。                                                                                                                                                                                                                                                                                             |
| **Property: `runTime` (readonly)**                                     | 总结已完成任务的收集运行时间的直方图摘要对象。                                                                                                                                                                                                                                                                                                               |
| **Property: `threads` (readonly)**                                     | 此池使用的 `Worker` 实例的数组。                                                                                                                                                                                                                                                                                                             |
| **Property: `queueSize` (readonly)**                                   | 当前等待分配给 Worker 线程的任务数。                                                                                                                                                                                                                                                                                            |
| **Property: `needsDrain` (readonly)**                                  | 指定提交的任务数量是否已超过池容量的布尔值。                                                                                                                                                                                                                                                                                                               |
| **Property: `utilization` (readonly)**                                 | 比较已完成任务的近似总平均运行时间与池的总运行时间容量的时间点比率。                                                                                                                                                                                                                                                                                               |
| **Property: `waitTime` (readonly)**                                    | 总结任务在队列中等待的收集时间的直方图摘要对象。                                                                                                                                                                                                                                                                                                    |
| **Static Property: `isWorkerThread` (readonly)**                       | 如果此代码作为 Worker 在 `Piscina` 线程池内运行，则为 `true`。                                                                                                                                                                                                                                                                                            |
| **Static Property: `version` (readonly)**                              | 提供此库的当前版本作为 semver 字符串。                                                                                                                                                                                                                                                                                                  |
| **Static Method: `move(value)`**                                       | 默认情况下，worker 函数返回的任何值在返回给 Piscina 池时都会被克隆，即使该对象能够被传输。`Piscina.move()` 方法可用于包装和标记可传输值，以便它们被传输而不是克隆。 |
| **Interface: `Transferable`**                                          | 对象可以实现 `Transferable` 接口以创建自己的自定义可传输对象。                                                                                                                                                                                                 |
