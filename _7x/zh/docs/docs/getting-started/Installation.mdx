本节将指导你开始使用 Piscina.js 的过程。我们将涵盖安装、基本使用和配置选项，以帮助你快速将 Piscina.js 集成到你的项目中。

要开始使用，你需要系统上安装了 Node.js 16.x 或更高版本。打开终端并运行以下命令：

<Tabs>
<TabItem value="npm">
```bash tab={"label":"npm"}
npm install piscina
```
</TabItem>
<TabItem value="yarn">
```bash tab={"label":"yarn"}
yarn add piscina
```
</TabItem>
<TabItem value="pnpm">
```bash tab={"label":"pnpm"}
pnpm add piscina
```
</TabItem>
<TabItem value="Bun">
```bash tab={"label":"Bun"}
bun add piscina
```
</TabItem>
</Tabs>

:::note
虽然可以使用 Bun 安装 Piscina，但其在 Bun 中运行时的行为无法保证。
:::
这将下载并安装最新版本的 Piscina.js 及其依赖项。
一旦安装了 Piscina.js，你就可以在代码中开始使用它了。
