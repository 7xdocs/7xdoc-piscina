## 设置主文件

<Tabs>
<TabItem value="Javascript">
```javascript title='main.js'
const path = require("path");
const Piscina = require("piscina");

// 创建一个新的 Piscina 实例指向你的 worker 文件
const piscina = new Piscina({
  filename: path.resolve(__dirname, "worker.js"),
});

// 使用 Piscina 运行一个任务
(async () => {
  const result = await piscina.run({ a: 4, b: 6 });
  console.log(result); // prints 10
})();
```
</TabItem>
<TabItem value="Typescript">
```javascript  title='main.ts'
import Piscina from "piscina";
import { resolve } from "path";
import { filename } from "./worker";

const piscina = new Piscina({
  filename: resolve(__dirname, "./workerWrapper.js"),
  workerData: { fullpath: filename },
});

(async () => {
  const result = await piscina.run({ a: 2, b: 3 }, { name: "addNumbers" });
  console.log("Result:", result);
})();
```
</TabItem>
</Tabs>

## 在 TypeScript 项目中使用 Worker 包装器文件

当使用 TypeScript 时，你需要使用 `workerWrapper.js` 文件来正确加载你的 worker 文件。该文件检查提供的文件路径是否以 `.ts` 结尾，并注册 `ts-node` 编译器来处理 TypeScript 文件。你可以在以下[指南](./typescript.mdx)中了解更多关于在 Piscina 中使用 Typescript 的信息。

## 使用异步函数或 Promise

Worker 可以是异步的，也可以返回一个 promise：
<Tabs>
<TabItem value="Javascript">
```javascript tab={"label":"Javascript"}
const { setTimeout } = require("timers/promises");

// 一个带有模拟延迟的异步 worker 函数
module.exports = async ({ a, b }) => {
  // 模拟一些带有延迟的异步活动
  await setTimeout(100);
  return a + b;
};
```

</TabItem>
<TabItem value="Typescript">
```javascript
const { setTimeout } = require("timers/promises");

interface WorkerInput {
  a: number;
  b: number;
}
// 一个带有模拟延迟的异步 worker 函数
module.exports = async ({ a, b }: WorkerInput): Promise<number> => {
  // 模拟一些带有延迟的异步活动
  await setTimeout(100);
  return a + b;
};
```
</TabItem>
</Tabs>

## 导出多个 Worker 函数

单个 worker 文件可以导出多个命名处理函数：
<Tabs>
<TabItem value="Javascript">
```javascript tab={"label":"Javascript"} title="worker.js"
"use strict";

function add({ a, b }) {
  return a + b;
}

function multiply({ a, b }) {
  return a * b;
}

add.add = add;
add.multiply = multiply;

module.exports = add;
```

</TabItem>
<TabItem value="Typescript">
```javascript title="worker.ts"
import { resolve } from "path";

export const filename = resolve(__filename);

function add({ a, b }: { a: number, b: number }): number {
  return a + b;
}

function multiply({ a, b }: { a: number, b: number }): number {
  return a * b;
}

export { multiply, add };
```
</TabItem>
</Tabs>


然后可以在提交任务时指定要导出的目标：
<Tabs>
<TabItem value="Javascript">
```javascript tab={"label":"Javascript"} title="main.js"
"use strict";

const Piscina = require("piscina");
const { resolve } = require("path");

// 使用 worker 文件初始化 Piscina
const piscina = new Piscina({
  filename: resolve(__dirname, "worker.js"),
});

// 并发运行多个任务
(async () => {
  const [sum, product] = await Promise.all([
    piscina.run({ a: 4, b: 6 }, { name: "add" }),
    piscina.run({ a: 4, b: 6 }, { name: "multiply" }),
  ]);
})();
```

</TabItem>
<TabItem value="Typescript">

```javascript tab={"label":"Typescript","span":2} title="main.ts"
import Piscina from "piscina";
import { resolve } from "path";
import { filename } from "./worker";

const piscina = new Piscina({
  filename: resolve(__dirname, "./workerWrapper.js"),
  workerData: { fullpath: filename },
});

// 并发运行多个任务
(async () => {
  const [sum, product] = await Promise.all([
    piscina.run({ a: 4, b: 6 }, { name: "add" }),
    piscina.run({ a: 4, b: 6 }, { name: "multiply" }),
  ]);
})();
```

## 可取消的任务

Piscina 支持任务取消，即使任务已经提交给 worker 并且正在积极处理中。例如，这可以用于取消运行时间过长的任务。

可以使用 `AbortController` 或 `EventEmitter` 取消任务。

### 使用 `AbortController`
<Tabs>
<TabItem value="Javascript">
```javascript title="main.js"
"use strict";

const Piscina = require("piscina");
const { resolve } = require("path");

// 设置带有 worker 文件的 Piscina
const piscina = new Piscina({
  filename: resolve(__dirname, "worker.js"),
});

// 运行一个任务并使用 AbortController 取消它
(async () => {
  const abortController = new AbortController();
  const { signal } = abortController;
  const task = piscina.run({ a: 4, b: 6 }, { signal });
  abortController.abort(); // 取消任务

  try {
    await task;
  } catch (err) {
    console.log("The task was canceled"); // 处理取消
  }
})();
```

</TabItem>
<TabItem value="Typescript">
```javascript  title="main.ts"
import Piscina from "piscina";
import { resolve } from "path";
import { filename } from "./worker";

// 设置带有 worker 和 workerWrapper 文件的 Piscina
const piscina = new Piscina({
  filename: resolve(__dirname, "./workerWrapper.js"),
  workerData: { fullpath: filename },
});

// 运行一个任务并使用 AbortController 取消它
(async () => {
  const abortController = new AbortController();
  const { signal } = abortController;
  const task = piscina.run({ a: 4, b: 6 }, { signal });
  abortController.abort(); // 取消任务

  try {
    await task;
  } catch (err) {
    console.log("The task was canceled"); // 处理取消
  }
})();
```

### 使用 `EventEmitter`

这里也可以使用普通的 Node.js EventEmitter，在这种情况下，在其上发出 abort 事件将具有相同的效果。
<Tabs>
<TabItem value="Javascript">
```javascript tab={"label":"Javascript"} title="main.js"
"use strict";

const Piscina = require("piscina");
const EventEmitter = require("events");
const { resolve } = require("path");

// 初始化带有 worker 文件的 Piscina
const piscina = new Piscina({
  filename: resolve(__dirname, "worker.js"),
});

// 运行一个任务并使用 EventEmitter 取消它
(async () => {
  const ee = new EventEmitter();
  const task = piscina.run({ a: 4, b: 6 }, { signal: ee });
  ee.emit("abort"); // 发出 'abort' 事件以取消任务

  try {
    await task;
  } catch (err) {
    console.log("The task was canceled"); // 处理取消
  }
})();
```

</TabItem>
<TabItem value="Typescript">
```javascript tab={"label":"Typescript","span":2} title="main.ts"
import Piscina from "piscina";
```
