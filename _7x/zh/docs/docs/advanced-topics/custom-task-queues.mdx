默认情况下，Piscina 使用一个简单的基于数组的先进先出 (fifo) 任务队列。当提交新任务且没有可用 worker 时，任务会被推送到队列中，直到有 worker 可用。

如果默认的 fifo 队列不够用，用户代码可以使用 Piscina 构造函数上的 `taskQueue` 选项，用自定义实现替换任务队列实现。

自定义任务队列对象_必须_实现 `TaskQueue` 接口，如下所示（使用 TypeScript 语法）：

```ts
interface Task {
  readonly [Piscina.queueOptionsSymbol]: object | null;
}

interface TaskQueue {
  readonly size: number;
  shift(): Task | null;
  remove(task: Task): void;
  push(task: Task): void;
}
```

一个使用打乱优先级的自定义任务队列的例子可以在 [`examples/task-queue`](https://github.com/piscinajs/piscina/tree/current/examples/task-queue) 中找到。

特殊符号 `Piscina.queueOptionsSymbol` 可以作为属性设置在提交给 `run()` 或 `runTask()` 的任务上，作为向自定义 `TaskQueue` 实现传递额外选项的一种方式。（请注意，因为队列选项是作为任务上的属性设置的，所以带有队列选项的任务不能作为 JavaScript 原语提交）。

### 内置队列

Piscina 还提供了 `FixedQueue`，这是一个基于 Node.js 项目中的 [`FixedQueue`](https://github.com/nodejs/node/blob/de7b37880f5a541d5f874c1c2362a65a4be76cd0/lib/internal/fixed_queue.js) 的更高性能的任务队列实现。

这里有一些基准测试来比较新的 `FixedQueue` 和 `ArrayTaskQueue`（当前默认值）。基准测试表明在 push 和 shift 操作上有实质性的改进，特别是在队列较大时。

<hr/>

**Queue size = 1000**

| (index) | Task Name                               | ops/sec   | Average Time (ns)  | Margin   | Samples |
|---------|-----------------------------------------|-----------|--------------------|----------|---------|
| 0       | 'ArrayTaskQueue full push + full shift' | '9 692'   | 103175.15463917515 | '±0.80%' | 970     |
| 1       | 'FixedQueue full push + full shift'     | '131 879' | 7582.696390658352  | '±1.81%' | 13188   |

<hr/>

**Queue size = 100,000**

| (index) | Task Name                               | ops/sec | Average Time (ns)  | Margin   | Samples |
|---------|-----------------------------------------|---------|--------------------|----------|---------|
| 0       | 'ArrayTaskQueue full push + full shift' | '0'     | 1162376920.0000002 | '±1.77%' | 10      |
| 1       | 'FixedQueue full push + full shift'     | '1 026' | 974328.1553396407  | '±2.51%' | 103     |

就 Piscina 本身的性能而言，使用队列大小为 100,000 个排队任务的 `FixedQueue` 可以使执行时间快达 6 倍。

用户可以从 `Piscina` 包中导入 `FixedQueue` 并将其作为 `taskQueue` 选项传递，以利用其优势。

### 使用 FixedQueue

这是一个如何使用 `FixedQueue` 的例子：

<Tabs>
<TabItem value="Javascript">
```js
const { Piscina, FixedQueue } = require("piscina");
const { resolve } = require("path");

// Create a Piscina pool with FixedQueue
const piscina = new Piscina({
  filename: resolve(__dirname, "worker.js"),
  taskQueue: new FixedQueue(),
});

// Submit tasks to the pool
for (let i = 0; i < 10; i++) {
  piscina
    .runTask({ data: i })
    .then((result) => {
      console.log(result);
    })
    .catch((error) => {
      console.error(error);
    });
}
```

</TabItem>
