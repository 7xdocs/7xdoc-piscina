此示例解释了如何使用 Piscina 进行 React 组件的服务端渲染 (SSR)。我们将比较使用 Piscina 的池化版本与非池化版本，以突显使用线程池进行 SSR 的好处。

首先，请确保你已安装以下依赖项：

```bash
npm install fastify fastify-piscina react react-dom lorem-ipsum
```
如果你在项目中使用 TypeScript，请同时安装：

```bash
npm install -D typescript @types/react @types/react-dom @types/node
```
worker 文件中的函数使用 `ReactDOMServer.renderToString()` 渲染两个 React 组件：`Greeting` 和 `Lorem`。

<Tabs>
<TabItem value="Javascript">

```javascript title="worker.js"
'use strict';

const React = require('react');
const ReactDOMServer = require('react-dom/server');
const { Greeting, Lorem } = require('./components');

module.exports = ({ name }) => {
  return `
  <!doctype html>
    <html>
    <body>
    <div id="root">${
      ReactDOMServer.renderToString(React.createElement(Greeting, { name }))
    }</div>
    ${
      ReactDOMServer.renderToString(React.createElement(Lorem))
    }
    <script src="/static/home.js"></script>
  </body>
  </html>`;
};
```

</TabItem>
<TabItem value="Typescript">


### 池化版本
在代码的池化版本中，我们设置了一个集成了 Piscina 的 Fastify 服务器。我们注册 `fastify-piscina` 插件，将其配置为使用带有 6 个线程的 `worker.js` 文件。根路由 (`/`) 使用 `fastify.runTask()` 在 worker 线程中执行渲染。

<Tabs>
<TabItem value="Javascript">

```javascript title="pooled.js"
'use strict';

const fastify = require('fastify')();
const { resolve } = require('path');

fastify.register(require('fastify-piscina'), {
  filename: resolve(__dirname, 'worker.js'),
  execArgv: [],
  minThreads: 6,
  maxThreads: 6
});

// Declare a route
fastify.get('/', async () => fastify.runTask({ name: 'James' }));

// Run the server!
const start = async () => {
  try {
    await fastify.listen(3000);
  } catch (err) {
    process.exit(1);
  }
};
start();

process.on('SIGINT', () => {
  const waitTime = fastify.piscina.waitTime;
  console.log('\nMax Queue Wait Time:', waitTime.max);
  console.log('Mean Queue Wait Time:', waitTime.mean);
  process.exit(0);
});
```

</TabItem>
<TabItem value="Typescript">

```typescript title="pooled.ts"

import { resolve } from 'path';
import { filename } from './worker';

const fastify = require('fastify')();

fastify.register(require('fastify-piscina'), {
  filename: resolve(__dirname, 'workerWrapper.js'),
  workerData: { fullpath: filename },
  execArgv: [],
  minThreads: 6,
  maxThreads: 6
});

// Declare a route
fastify.get('/', async () => fastify.runTask({ name: 'James' }, { name: 'renderPage' }));

// Run the server!
const start = async () => {
  try {
    await fastify.listen(3000);
  } catch (err) {
    process.exit(1);
  }
};
start();

process.on('SIGINT', () => {
  const waitTime = (fastify as any).piscina.waitTime;
  console.log('\nMax Queue Wait Time:', waitTime.max);
  console.log('Mean Queue Wait Time:', waitTime.mean);
  process.exit(0);
});
```

### 非池化版本

在服务器的非池化版本中，我们执行与池化版本相同的渲染，但没有线程池或 worker 管理。根路由 (`/`) 在请求处理程序中同步渲染 React 组件。

<Tabs>
<TabItem value="Javascript">

```javascript title="unpooled.js"
'use strict';

const fastify = require('fastify')();
const React = require('react');
const ReactDOMServer = require('react-dom/server');
const { Greeting, Lorem } = require('./components');

// Declare a route
fastify.get('/', async () => {
  const name = 'James';
  return `
  <!doctype html>
    <html>
    <body>
    <div id="root">${
      ReactDOMServer.renderToString(React.createElement(Greeting, { name }))
    }</div>
    ${
      ReactDOMServer.renderToString(React.createElement(Lorem))
    }
    <script src="/static/home.js"></script>
  </body>
  </html>`;
});

// Run the server!
const start = async () => {
  try {
    await fastify.listen(3000);
  } catch (err) {
    process.exit(1);
  }
};
start();
```

</TabItem>
<TabItem value="Typescript">

```typescript title="unpooled.ts"
import fastify from 'fastify';
import React from 'react';
import ReactDOMServer from 'react-dom/server';
import { Greeting, Lorem } from './components';

const server = fastify();

// Declare a route

    }</div>
    ${
      ReactDOMServer.renderToString(React.createElement(Lorem))
    }
    <script src="/static/home.js"></script>
  </body>
  </html>`;
});

// Run the server!
const start = async () => {
  try {
    await server.listen(3000);
  } catch (err) {
    process.exit(1);
  }
};
start();
```

使用 Piscina 的池化版本为服务端渲染提供了几个优势：
- 它每秒处理的请求明显更多（平均 1,348.9 对 395.6）。
- 它的延迟更低（平均 6.9ms 对 25.03ms）。
- 它处理的数据更多（平均 4.68 MB/sec 对 1.36 MB/sec）。
